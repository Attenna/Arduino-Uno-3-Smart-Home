Arduino Uno 3 Smart Home · Web 控制台

智能家居演示项目：Arduino Uno 3 主控 + 传感/输出模块 + Python 服务端 + 网页控制台。 本页面为项目入口页，用于让站点根路径可正常访问。

说明：本入口页是纯静态文件，可直接打开。 完整的控制台页面（仪表盘、登录、房间、硬件、历史、自动化等）由 PC_Test/web/templates/ 下的服务端模板渲染，需要运行 Python 服务端后才能真正使用； 在当前静态托管环境下，这些页面即使能访问到文件，也无法正常渲染与调用接口。
