# A 板红外链路诊断

临时诊断固件，使用与生产 A 板相同的 IRremote 4.7.1 和 D3 接收口。
初始化方式与旧版 `tools/ir-raw-capture` 一致：
`IrReceiver.begin(3, DISABLE_LED_FEEDBACK)`。

编译：在此目录执行 `pio run`。

烧录前必须备份运行时、记录香橙派仓库 main 提交并读取 A 板当前 Flash。
停止占用 A 板串口的网关后才能烧录。串口波特率为 115200。
诊断期间风扇 A1 固定 LOW，其他传感器和执行器业务暂停；本固件不接收控制命令。
完成后必须恢复备份的 A 板固件，并恢复网关和服务健康。

输出含义：

- `INPUT level/edges/frames`：D3 当前电平、轮询观察到的累计跳变数、收到的帧数。
- `FRAME protocol/address/command/flags/bits/rawlen`：库的原始解码结果，不过滤重复帧或未知协议。
- `edges` 是轮询观察值，不是精密脉冲计数；串口打印时可能漏计。

测试时先松开按键两秒，再按住三秒，重复几次。持续没有跳变只能说明
当前 D3 未观察到接收模块输出变化，不能单凭此结果认定传感器损坏。
有跳变但没有有效帧时检查协议、供电、干扰和定时；有有效帧时再检查生产固件与网关规则。

此工具不会写入规则、数据库或部署版本标记，不应作为常驻固件。
