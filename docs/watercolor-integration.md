# 水彩首页与业务前端整合

本地整合分支 `feat/watercolor-dashboard`，基于 `c48dbb2`。

## 页面与功能对应

| 页面 | 保留的业务功能 | 本轮整合 |
| --- | --- | --- |
| `/` | 状态轮询、灯光颜色与档位、风速、门窗、历史图表、硬件诊断 | 水彩房间、物件点击、状态驱动动效、离线与过期提示，精细控制折叠到下方 |
| `/rooms` | 房间设备与全部控制 | 从顶部导航及首页精细控制进入 |
| `/access` | 人员、人脸与 RFID 录入、摄像头、通行记录 | 导航与门口读卡器点击进入，沿用现有业务 |
| `/hardware` | 硬件连接、工具与诊断 | 增加显式导航与首页入口 |
| `/automation` | Blockly 规则、全局状态、OLED 轮播 | 首页场景入口及电子屏点击进入 |
| `/voice` | 语音状态、唤醒、对话 | 首页及顶部导航进入 |
| `/history` | 环境与设备历史 | 首页及顶部导航进入 |
| `/settings` | 系统与家庭配置 | 顶部导航进入 |

## 状态与控制

- 首页复用 `main.js` 的 `/api/status` 轮询及 `status:update` 事件，避免新增状态轮询。
- 门窗、灯光、风扇通过现有 `/api/door`、`/api/window`、`/api/light`、`/api/fan` 下发，复用鉴权、请求超时与命令序号机制。
- 蜂鸣器通过现有 `/api/hardware/tool` 调用 `buzzer`。
- 场景动效只由状态接口确认值驱动。请求进行中禁用同设备重复操作，失败保持原状态。
- 超过 12 秒收不到状态时清除动态显示、禁用控制，传感器过期显示空值。
- B 板 ACK 过期时，仍允许通过在线硬件桥重新确认状态，避免长时间无指令后无法恢复控制。
- 首页通行摘要读取 `/api/access/logs`，使用文本节点渲染人员与记录。

## 留言与视觉资源

水彩素材来自已确认的本地 Demo。门窗外景为固定图层，门窗扇从同一关闭图中裁切并绕铰链变换。

留言板暂保存在当前浏览器的 `localStorage`，界面明确标注“本机留言板”。跨用户和跨设备留言同步需要后续数据库与 API 支持。

## 本轮验证边界

本轮以本机桌面网页整合为目标，使用独立本地数据库和关闭串口的服务进行验证。
香橙派真实设备交互、分支真机测试及合并部署需要设备恢复在线后执行。

### 2026-11-15 本机验证结果

- 独立测试环境补齐音频、OpenCC 等依赖后，Python 全量测试 347 项全部通过。
- 新增水彩交互测试 6 项全部通过，覆盖失败不误开门、状态驱动动画、离线过期、ACK 过期恢复、零值传感器与重复点击。
- 现有 JavaScript 测试连同新增用例共 26 项，24 项通过。两项失败分别为历史页光照字段与旧空调样式标记，在未修改的基线文件组合中复现。
- 登录后八个页面以及状态、门禁日志、自动化规则、就绪检查和新增样式脚本均返回 HTTP 200。
- 1440px 桌面浏览器检查中，首页、门禁、硬件和自动化均无横向溢出，无未捕获脚本异常，留言板可打开。
- 本机服务使用关闭串口模式，现场显示离线与未确认状态。真实执行器动作尚待真机验证。
