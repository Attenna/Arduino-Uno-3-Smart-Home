# 红外遥控器 1–4 键绑定

| 按键 | NEC command | 动作 |
|---|---|---|
| 1 | 0x45 | 灯开启 / 关闭 |
| 2 | 0x46 | 风扇开启 / 关闭 |
| 3 | 0x47 | 门打开 / 关闭 |
| 4 | 0x44 | 窗打开 / 关闭 |

四条规则默认启用，通过 Web 自动化引擎执行，无需重烧 Arduino。
基于数据库最近一次成功下发的状态选择分支。灯开启亮度为 100%，沿用当前灯光样式；
风扇开启请求为 60（当前硬件仅支持开关）。门打开 90°，窗全开 120°。
窗当前处于 normal（45°）时，按键 4 会先全开，再按关闭。
每条规则冷却 1 秒。键码沿用仓库已有按键表，需现场核对遥控器实际事件。

## 自动化优先级

每个按键设置对应的 `g:手动优先_*` 为 true。
现有手动优先解除规则在状态连续为 true 达到 30 秒后解除，普通自动化随后可恢复。
温度/光照规则在手动优先期间让位；无人关灯/风扇规则在灯或风扇任一手动优先期间暂缓。
窗自动恢复 45° 同样让位。雨水/烟雾关窗始终生效；数据陈旧或危险状态未确认解除时不开窗。
门禁、触摸开门的既有延时关门动作仍会执行。
同一手动优先变量已经为 true 时再次设置 true 不重新计时。

## 升级

预设版本从 8 升为 9。首次启动会删除旧 `ir_fan_toggle`（键 1 风扇示例），
补入四条新规则。其他用户规则保留；普通默认规则的手动优先条件仅在其逻辑未被修改时补入。
用户自建的相同按键规则不删除，部署前应检查并停用重叠映射。
新规则也可在 `/automation` 编辑或停用。

## 验收

1. 串口事件确认 1–4 分别为 command 69、70、71、68。
2. 每键连续按两次（间隔超过 1 秒），对应设备开、关，其他设备不变。
3. 雨水或烟雾报警时，按键 4 不能开窗。
4. 检查灯、风扇、窗操作后，普通默认自动化在手动优先期间不覆盖。

必须通过仓库要求的评审合并后，再同步 main 并部署香橙派。
