🧩 积木式自动化（当触发 → 如果条件 → 执行动作 / 否则切换状态）

从左侧工具箱拖积木：紫色「规则」块每个代表一条规则，槽位依次放 触发块（橙色）、 条件块（蓝色，可叠多个）、执行块（绿色，从上往下依次执行）； 「否则」槽可放状态切换动作（如雨停恢复 45°），也可留空。改完点「保存全部规则」立即生效。 内置联动（温度控风扇、光敏调光、雨水关窗、烟雾报警、门禁自动关门、触摸/按键切换等） 已全部变成下面的默认规则积木，可改名/改阈值/停用/删除； 误删用「恢复内置规则」找回。手动优先：你在面板/语音手动操作某设备后， 该设备进入「手动冷却窗口」，期间自动规则与档位覆盖自动让位，绝不把你要的状态改回去。
积木引擎（Blockly）未能加载，请按 Ctrl+F5 强制刷新；若仍失败，请确认 web 容器已包含本地积木资源（static/vendor/blockly）。
